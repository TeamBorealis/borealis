**Borealis** 1.5.1 lets the Homebrew Creator change content you didn't make: override a System Reference Document or imported element in place, and every character that uses it gets the change.

**Download for your platform at [borealisbuilder.com](https://borealisbuilder.com)**, or pick a file below.

| Platform | File |
|---|---|
| macOS (Apple silicon, macOS 10.15 or later) | `Borealis_1.5.1_aarch64.dmg` |
| Windows (x64) | `Borealis_1.5.1_x64-setup.exe` |
| Linux (x86_64), any distribution | `Borealis_1.5.1_amd64.AppImage` |
| Debian / Ubuntu | `Borealis_1.5.1_amd64.deb` |
| Fedora / openSUSE | `Borealis-1.5.1-1.x86_64.rpm` |
| Android (64-bit ARM), sideload | `Borealis_1.5.1_arm64.apk` |

Installing 1.5.1 over any earlier version keeps your characters, content and settings. On Windows, macOS and the Linux AppImage, **Install and restart** in the update notice installs it for you.

### New in 1.5.1
- **Override the original.** **Copy to homebrew** in the Compendium and the builder now asks how: **Make a variant (copy)**, as before, or **Override the original**, which changes the element itself. **New element** has **Override the original...** next to New from copy. Pick any installed element, from the System Reference Document or from content you imported, change it in the creator and save it in your homebrew pack: it keeps its place everywhere, and characters that already have it keep it and get the change, with nothing to pick again.
- **Your change always wins.** An override counts after all other content, whatever order your packs load in, so another pack can't undo it.
- **Changed by, and Revert.** The element's description in the builder and the Compendium says which of your packs changed it, with **Revert** to bring the original back (and Undo in case you change your mind). In the creator, overrides are marked in the element list ("Changes" and the book's name), and Delete on one reverts it.
- **When the book changes.** If you import that book again and the element is different now, the creator tells you on the element: save to keep your version, or revert to use the new one. If the book is turned off or removed, the override says it has no effect until the book is back.
- **Sharing stays safe.** When you export a pack, changes to elements of content you imported are left out together with copied text, unless you choose otherwise; changes to System Reference Document elements are always included.
- **Accidental duplicates are flagged.** An element of your pack that has the same id as an element of another pack gets a warning, so a clash is never silent.
- **On phones too,** with the same choices, the notice at the top of the editor and Changed by in the description.
- **Update your other devices first.** A pack with overrides needs 1.5.1: Borealis 1.5.0 can't open it, so update every device before you send it there.
